# Wellington Taureka

Independent developer building practical tools for AI security, code analysis,
network diagnostics, and browser-based engineering.

## Current focus

- Semantic-layer defence against prompt injection
- Tools that examine what code does, not only how it is written
- Small, focused applications that solve a clear problem

## Featured projects

### [PSCS Semantic Security](https://github.com/BruinGrowly/PSCS-Semantic-Security)

Semantic-layer prompt-injection defence that separates untrusted instructions
from authority while preserving the legitimate task.

### [PNG Civil Engineering CAD Software](https://github.com/BruinGrowly/PNG-AutoCad-Software)

A free, browser-based CAD application designed for civil engineers in Papua New
Guinea.

### [Python Code Harmonizer](https://github.com/BruinGrowly/Python-Code-Harmonizer)

A semantic code-analysis tool for examining Python code structure and
behaviour.

### [COBOL Code Harmonizer](https://github.com/BruinGrowly/COBOL-Code-Harmonizer)

Detects semantic mismatches between COBOL procedure names and their actual
behaviour.

### [Network Pinpointer](https://github.com/BruinGrowly/Network-Pinpointer)

A network diagnostic and topology-analysis tool for inspecting connectivity,
security, performance, and visibility.
